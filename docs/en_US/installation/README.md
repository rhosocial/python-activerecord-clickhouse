# Installation

This section covers installing the ClickHouse backend and its dependencies.

> ⚠️ **Prerequisite**: This backend depends on the core library
> `rhosocial-activerecord>=1.0.0.dev30`. Until the core library `1.0.0.dev30` is
> officially published to PyPI, `pip install rhosocial-activerecord-clickhouse`
> cannot resolve dependencies. Follow the "install from source" steps below.

- [Installation guide](installation.md)
- [Connection configuration](configuration.md)
