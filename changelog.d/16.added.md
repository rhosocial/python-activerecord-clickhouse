Added ClickHouse implementations of the four migration change-point suggestion protocols: `ColumnReorderSuggestionSupport`, `TableConstraintChangeSuggestionSupport`, `TableIndexChangeSuggestionSupport` and `PartitionSchemeChangeSuggestionSupport`. Column reorder and index change return an explicit `False` with the engine evidence recorded in each module (no node repositions an existing column by name; ALTER INDEX has no modeling node, although ClickHouse's skip indexes do support the commands). Constraint changes return a real drop/add chain for CHECK constraints, built from existing expression nodes. Partition scheme changes dispatch a maintenance plan to the nine existing partition statement nodes behind each capability probe and refuse the five verbs missing from ClickHouse's reference.
