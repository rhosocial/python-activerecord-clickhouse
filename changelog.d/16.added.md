Added ClickHouse implementations of the four migration change-point suggestion protocols: `ColumnReorderSuggestionSupport`, `TableConstraintChangeSuggestionSupport`, `TableIndexChangeSuggestionSupport` and `PartitionSchemeChangeSuggestionSupport`. Column reorder returns an explicit `False` with the engine evidence recorded in its module (no node repositions an existing column by name). Index change returns a real `ALTER TABLE ... ADD INDEX` / `DROP INDEX` chain built from live skip-index declarations, and keeps refusing the shapes its nodes cannot express. Constraint changes return a real drop/add chain for CHECK constraints, built from existing expression nodes. Partition scheme changes dispatch a data-preserving maintenance plan to the five safe partition statement nodes behind each capability probe, refuse destructive or data-moving operations, and refuse the five verbs missing from ClickHouse's reference.
