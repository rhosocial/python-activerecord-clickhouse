Claim ClickHouse Snowflake machine ids atomically. Machine ids were allocated by probing for a free value, so two processes starting together could claim the same id and emit identical ids, making rows from different writers indistinguishable. The slot is now claimed with an `O_CREAT|O_EXCL` create, which the kernel makes atomic; claim files are namespaced by boot marker so slots cannot outlive a reboot, a slot whose owning pid is gone is reclaimed, and an exhausted table raises instead of reusing an id. Also collect the accompanying backend package reorganisation, removal of two legacy re-export shims, the show-expression namespace move, a README/`.claude` knowledge base rewrite, and the changelog fragment check unified across all eleven repositories.
