Added `UnsupportedFeatureError` guards in MySQL dialect's `format_add_column_action`, `format_drop_column_action`, and `format_drop_table_constraint_action` overrides so that requesting `if_not_exists=True` / `if_exists=True` on `AddColumn` / `DropColumn` / `DropTableConstraint` raises a clear error with a hint to pre-check `information_schema.COLUMNS` and `information_schema.TABLE_CONSTRAINTS`. MySQL does not support these `IF [NOT] EXISTS` qualifiers on `ALTER TABLE`.
