Added MySQL dialect support for previously-missing SQL statements identified in the coverage-gap analysis: `RENAME TABLE` (atomic multi-table rename), `TRUNCATE TABLE` (with capability guards for unsupported RESTART IDENTITY / CASCADE), `ALTER TABLE ... ALTER COLUMN {SET DEFAULT | DROP DEFAULT}`, whole-table maintenance statements (`ANALYZE` / `CHECK` / `CHECKSUM` / `OPTIMIZE` / `REPAIR TABLE`), stored routines (`CREATE` / `DROP PROCEDURE`, `CREATE` / `DROP FUNCTION`, `CALL`), the `TABLE` statement and `VALUES` table value constructor (8.0.19+), `LOAD XML`, and administrative utility commands (`FLUSH`, `RESET`, `KILL`, `INSTALL` / `UNINSTALL COMPONENT` / `PLUGIN`, `CACHE INDEX`, `LOAD INDEX INTO CACHE`, `CLONE`, `RESTART`, `BINLOG`, `HANDLER`, `DO`, `SHUTDOWN`, `HELP`, `CREATE` / `DROP USER`, `GRANT`, `REVOKE`). Each feature ships an expression class, a dialect mixin, and a runtime-checkable protocol following the Expression-Dialect separation principle.
