Partition-scheme-change suggestions no longer emit statements that delete, overwrite, export or reset table rows. `DROP PARTITION`, `REPLACE PARTITION FROM`, `MOVE PARTITION TO TABLE` and `CLEAR COLUMN/INDEX IN PARTITION` now return `False`: a bare old/new partition declaration is not an explicit maintenance request or a data-preserving migration plan. `DETACH` is only suggested when the same answer attaches the partition back; standalone `DETACH` and `ATTACH` without that chain are refused. `FREEZE`, `UNFREEZE` and `OPTIMIZE ... FINAL` remain available because they leave the table's rows in place.
