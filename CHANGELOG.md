# Changelog

## [v1.0.0.dev1] - 2026-08-23

### Added

- Initial development release of the ClickHouse backend for rhosocial-activerecord: ActiveRecord CRUD over clickhouse-connect (HTTP) with client-side snowflake ids, a capability-gated dialect with fast-fail semantics, schema introspection via `system.*` tables, EXPLAIN/SHOW support, a CLI, and full shared-testsuite feature coverage (basic/events/interface/mixins/query/relation).
